🍟 麦麦优选智能体（maimai-youxuan）
MCP + WorkBuddy 智能点餐规划助手 ｜ 麦当劳程序员节创意开发大赛参赛作品（单人参赛）
基于麦当劳官方 mcd-mcp MCP 数据的智能点餐规划助手。它像一个懂麦当劳的随身点餐参谋：帮你选门店、搭套餐、比价格、查优惠，输出可直接照抄的点餐清单——全程只做规划建议，不下单、不支付。
🍔 它能做什么
- 🍽️ 核心点餐搭配：按人数、口味、预算自由组合套餐，输出菜品清单、原价、优惠抵扣、实付总价，多人自动拆账分摊（AA 一目了然）
- 🏬 门店智能筛选：一键查出附近所有麦当劳门店，可按「24 小时营业」「得来速」「距离」等条件过滤，列出营业时间与地址
- 🎁 限定新品与活动查询：实时查询当前限时活动、联名新品、限定周边（如龙焰系列、联名徽章），并跨门店核对库存与在售状态
- 📋 菜单实时查询：读取任意门店的实时菜单与商品价格，标注套餐/单品信息
- 🎫 优惠券查询：查询门店当前可用优惠券，自动判断能否叠加到你的点餐方案
- 💰 线上线下比价：堂食 vs 得来速 vs 麦麦送（外送）多渠道实时计价对比，配送费、打包费逐项列明，用数据帮你理性决策
- 🥗 营养信息展示：方案附带热量与钠含量参考（仅展示，不构成饮食建议）
- ⚖️ 理性消费提示：所有价格为官方 MCP 实时数据，比价结果只列事实与场景参考，不替用户做决定，倡导按需点餐
📦 安装方法
① MCP 连接器配置
将 mcp-config.example.json 复制为 mcp-config.json，把环境变量占位符 ${MCP_TOKEN} 替换为你自己的麦当劳 MCP Token（请勿把真实 Token 提交到仓库）：
{
  "mcpServers": {
    "mcd-mcp": {
      "command": "...",
      "args": ["..."],
      "env": { "MCP_TOKEN": "${MCP_TOKEN}" }
    }
  }
}
② Skill 安装
把本项目的 SKILL.md 放入 WorkBuddy 技能目录：
~/.workbuddy/skills/maimai-youxuan/SKILL.md
安装后在对话中用以下关键词即可触发：
- 「帮我点麦当劳 / 搭配一个麦当劳套餐」
- 「附近有哪些麦当劳？有 24 小时营业的吗？」
- 「堂食和麦麦送哪个划算？」
- 「麦当劳现在有什么新品 / 限定活动？XX 还有货吗？」
💬 使用示例
示例 1：两人午餐搭配
用户：我在上海松江，两个人的麦当劳午餐，堂食，两人都想要汉堡 + 饮料，给出 2 套方案，分开算各自分摊。
助手：已定位麦当劳上海松江餐厅（24h 营业）。方案 1 双套餐组合：实付 72.5 元，人均 36.25 元；方案 2 随心配 1+1 ×2：实付 29.8 元，人均 14.9 元。附营养参考，选定后请前往官方 APP 或到店点餐。
示例 2：线上线下比价
用户：我要一个汉堡、薯条、饮料、冰淇淋，帮我定套餐，看看堂食和外卖哪个划算。
助手：推荐巨无霸三件套 + 麦旋风。堂食实付 ¥52.0；麦麦送实付 ¥69.2（含配送费 ¥6 + 打包费 ¥2.7）。到店更省 17.2 元，麦旋风外送途中会变软，建议堂食/自取。本智能体不下单，请到官方渠道完成点餐。
